# 📦 Kho — Website Tĩnh Trải Nghiệm UI & Hiệu Ứng Web

Kho là một dự án website tĩnh được xây dựng bằng HTML, CSS và JavaScript, tập trung vào việc tạo ra các hiệu ứng giao diện, trang tương tác và trải nghiệm người dùng mang tính sáng tạo. Đây là một project thực hành giúp nâng cao kỹ năng frontend cơ bản và xử lý DOM.

## ✨ Điểm Nổi Bật

* 🎨 Giao diện web nhiều trang (multi-page)
* ✨ Hiệu ứng tương tác và animation đơn giản
* 💌 Các trang chức năng như mail, love, hiệu ứng hình ảnh
* 🎵 Tích hợp âm thanh và media assets
* 📱 Thiết kế sáng tạo, mang tính thực hành cao
* ⚡ Chạy trực tiếp trên trình duyệt

## 🏗️ Cấu Trúc Dự Án

Kho được xây dựng theo dạng website tĩnh:

### Trang chính

* `index.html`, `index1.html`, `index2.html`
* Hệ thống điều hướng giữa các trang nội dung

### Module chức năng

* `mail.html` — giao diện hiển thị nội dung mail
* `love/` — hiệu ứng tương tác cảm xúc
* `sound/` — âm thanh và hiệu ứng audio

### Tài nguyên hệ thống

* `css/` — file style chính và phụ
* `js/`, `script.js`, `app.js` — logic xử lý tương tác
* `image/`, `image1/`, `img/` — tài nguyên hình ảnh

## 💻 Công Nghệ Sử Dụng

* HTML5
* CSS3
* JavaScript (Vanilla)
* Static Web Architecture
* Media assets (audio/image integration)

## 🎯 Mục Tiêu Dự Án

Kho được phát triển nhằm:

* Thực hành xây dựng website tĩnh nhiều trang
* Rèn luyện kỹ năng HTML/CSS/JS cơ bản
* Hiểu cách tạo hiệu ứng UI/UX đơn giản
* Xây dựng các trải nghiệm web sáng tạo

## 🚀 Định Hướng Phát Triển

* Nâng cấp giao diện hiện đại hơn
* Tối ưu responsive cho mobile
* Chuyển sang framework (React/Vue)
* Thêm backend để lưu dữ liệu
* Cải thiện hiệu ứng animation nâng cao
* Tối ưu tốc độ và UX tổng thể

---

Kho là một dự án frontend thực hành giúp củng cố nền tảng phát triển web, đặc biệt trong việc xử lý giao diện, hiệu ứng và cấu trúc website nhiều trang.
